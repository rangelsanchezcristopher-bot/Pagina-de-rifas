# Página de Rifas

Este es un proyecto de página web que permite gestionar rifas. Contiene un backend y una interfaz para la administración de rifas.

## Estructura del proyecto
- `backend`: Carpeta con la lógica de servidor.
- `Interfaz`: Carpeta con los archivos de la interfaz de usuario.

## Cómo usar
- Para correr el backend, sigue las instrucciones en la carpeta `backend`.
- Para ver la interfaz, abre los archivos en la carpeta `Interfaz` en tu navegador.
